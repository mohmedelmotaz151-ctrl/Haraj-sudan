# حراج السودان

منصة إعلانات مبوبة مستقلة للسوق السوداني.

- الجمهور: أفراد وشركات.
- العملة: الجنيه السوداني (SDG).
- الواجهة: عربية RTL ومتجاوبة.
- الاستضافة المستهدفة: Vercel.
- قاعدة البيانات: Firebase جديد ومستقل (يُربط بعد إنشاء المشروع).
- الربح: مؤجل.

## التشغيل
```bash
npm install
npm run dev
```

## الحالة الحالية
واجهة أولية قابلة للتصفح مع أقسام وبحث وتصفية وبيانات إعلانات تجريبية. يلزم ربط Firebase لإضافة الحسابات والنشر الحقيقي والمراسلة والصور، ثم إعداد مشروع Vercel.

لا تضع مفاتيح Firebase أو أسرار الخادم في المستودع.
