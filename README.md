# حراج السودان

منصة إعلانات مبوبة عربية للأفراد والشركات، بعملة الجنيه السوداني (SDG).

## التقنية
- Next.js 15 / React 19 / TypeScript
- Firebase Authentication وCloud Firestore وCloud Storage (إعدادات الربط موجودة في هذا المستودع)
- Vercel للاستضافة

## إعداد Firebase المستقل
1. أنشئ مشروع Firebase جديداً باسم خاص بحراج السودان، ولا تستخدم مشروعاً تابعاً لأي تطبيق آخر.
2. أضف تطبيق Web من إعدادات المشروع وانسخ قيم إعدادات Firebase.
3. فعّل مزود Email/Password من Authentication.
4. أنشئ قاعدة Firestore في وضع الإنتاج، ثم انشر محتوى `firestore.rules`.
5. فعّل Storage ثم انشر محتوى `storage.rules`.
6. انسخ `.env.example` إلى `.env.local` وأدخل القيم الست من إعدادات تطبيق الويب.
7. أضف متغيرات البيئة نفسها في إعدادات مشروع Vercel قبل النشر.

## التشغيل
```bash
npm install
npm run dev
```

عند عدم إدخال إعدادات Firebase، تعيد `getFirebaseServices()` القيمة `null` حتى لا يفشل البناء بسبب غياب مفاتيح المشروع.

## نموذج بيانات الإعلانات
مجموعة `listings`: العنوان والوصف والسعر والعملة والمدينة والقسم ومعرف المالك وحالة الإعلان وتاريخ الإنشاء. يبدأ الإعلان بحالة `pending` ولا يظهر للعامة إلا بعد اعتماده وتغيير حالته إلى `published` بواسطة مشرف موثوق.

## تنبيه
الواجهة الحالية ما زالت تعرض بيانات تجريبية. إعدادات Firebase هنا هي أساس الربط وليست دليلاً على إنشاء مشروع Firebase أو نشر الموقع أو تفعيل تسجيل الدخول حتى الآن.
